# Clear Vision Initiative

A website for the Clear Vision Initiative (Vision for Latino Vision), a project working to make eye exams and glasses affordable and accessible for Latino communities in the United States. The site explains the barriers the initiative targets (cost, language and access) and invites visitors to support it.

## Features

- Animated hero and highlight carousel with synced video clips (GSAP)
- Bilingual messaging aimed at Spanish speaking families
- Multi page layout with React Router: About Us, Mission Statement, More Information, Support
- Responsive design with Tailwind CSS

## Tech stack

React 19, Vite, Tailwind CSS, GSAP, React Router, Three.js (React Three Fiber)

## Run it locally

The app lives in the [`Vision/`](Vision/) folder.

```bash
cd Vision
npm install
npm run dev      # http://localhost:5173
```

Build for production with `npm run build`.
